# 🌐 Samia Akter Erin — Personal Portfolio

A modern, responsive, and interactive personal portfolio website built to showcase my academic background, technical skills, projects, certifications, achievements, and professional contact information.

The portfolio supports **English and Bengali languages**, **Dark Mode**, **Eye Protection Mode**, animated sections, project filtering, certificate image viewing, and responsive design for desktop and mobile devices.

---

### 🌐 Multilingual Support

The website supports:

- 🇬🇧 English
- 🇧🇩 বাংলা

Users can switch languages using the language selector in the navigation bar.

### 🌙 Dark Mode

A dedicated dark mode toggle allows users to switch between light and dark themes.

The selected theme is saved using `localStorage`, so the preference remains after refreshing the page.

### 👁️ Eye Protection Mode

An Eye Protection Mode is included to reduce visual strain using a warm-toned visual filter.

The selected preference is also saved in `localStorage`.

### 📱 Responsive Design

The website is responsive and optimized for:

- 💻 Desktop
- 💻 Laptop
- 📱 Tablet
- 📱 Mobile

### 🎞️ Animations

The website uses **AOS (Animate On Scroll)** for smooth section animations.

Additional CSS animations include:

- Floating profile animation
- Pulse animation
- Hover effects
- 3D card effects
- Smooth transitions

### 📌 Sticky Contact Bar

A floating contact bar is displayed on the right side of the page with quick access to:

- Email
- GitHub
- LinkedIn

### ⬆️ Back to Top

A floating Back to Top button allows users to quickly return to the beginning of the page.

### 🖼️ Image Viewer

Certificates and achievement images can be opened in a dedicated full-screen image viewer.
